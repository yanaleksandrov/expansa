# Введение

`Json` — тонкая обёртка над `json_encode()` и `json_decode()` с настройками по умолчанию, которые
подходят для CMS: кириллица и слеши не экранируются, а ошибки не бросают исключений.

Работать можно через фасад `Expansa\Facades\Json` или напрямую с классом `Expansa\Codecs\Json`.

```php
use Expansa\Facades\Json;

$json  = Json::encode(['title' => 'Привет', 'url' => 'https://example.com/a']);
// {"title":"Привет","url":"https://example.com/a"}

$value = Json::decode($json, true); // ['title' => 'Привет', 'url' => 'https://example.com/a']
```

## Кодирование

```php
Json::encode(mixed $value, bool $ascii = false, bool $pretty = false, bool $forceObjects = false): string
```

| Параметр | Что делает |
|---|---|
| `$ascii` | экранирует всё, что не ASCII: `"При"` вместо `"При"` |
| `$pretty` | форматирует вывод с отступами |
| `$forceObjects` | кодирует списки как объекты: `{"0":"a","1":"b"}` вместо `["a","b"]` |

Слеши не экранируются никогда: `https://example.com`, а не `https:\/\/example.com`.

Невалидный UTF-8 заменяется символом `�` (U+FFFD). Один битый символ, например из обрезанной
посередине строки, не мешает закодировать всё остальное значение.

Если значение закодировать нельзя (`NAN`, `INF`, ресурс, слишком глубокая вложенность),
возвращается пустая строка `''`.

```php
Json::encode("bad \xB1 utf8"); // "bad � utf8"
Json::encode(NAN);             // ''
```

## Декодирование

```php
Json::decode(string $json, bool $forceArrays = false): mixed
```

По умолчанию объекты возвращаются как `stdClass`, с `$forceArrays = true` — как ассоциативные
массивы. В коде CMS почти всегда нужен второй вариант.

Целые числа больше `PHP_INT_MAX` возвращаются строками, чтобы не терять точность, например у
ID из внешних систем.

При невалидном JSON возвращается `null`. Литерал `null` тоже декодируется в `null`, поэтому если
нужно отличить одно от другого, сначала проверьте строку через `isValid()`.

```php
Json::decode('{"a":{"b":1}}', true);  // ['a' => ['b' => 1]]
Json::decode('12345678901234567890'); // '12345678901234567890'
Json::decode('{bad');                 // null
Json::decode('');                     // null
```

## Проверка

`isValid()` проверяет, что значение — строка с валидным JSON. Строка при этом не декодируется,
поэтому это быстрее, чем `decode()`, и не расходует память на результат. Для значений других
типов возвращается `false`.

```php
Json::isValid('{"a":1}'); // true
Json::isValid('{bad');    // false
Json::isValid(123);       // false
```

## Производительность

Почти всё время уходит на нативные `json_encode()` и `json_decode()`, накладные расходы обёртки
в пределах погрешности замеров. Ошибки определяются через `json_last_error()`, а не через
`JSON_THROW_ON_ERROR`: на невалидном JSON исключения вдвое медленнее.
