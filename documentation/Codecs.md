# Кодеки

Кодек переводит данные между PHP и внешним форматом: строкой JSON, файлом CSV, шаблоном даты для
JavaScript. Все кодеки лежат в `Expansa\Codecs` и устроены одинаково:

- **`encode()`** — из PHP во внешний формат, **`decode()`** — обратно.
- **Состояния нет.** Фасад (`Expansa\Facades\Json`) и прямой вызов класса (`new Expansa\Codecs\Json()`)
  равноценны.
- **Зависимостей от других пакетов `expansa/` нет**, поэтому кодек можно использовать где угодно.
- **Ошибки во входных данных не бросают исключений**, а возвращают пустое значение (`''`, `null`
  или `[]`). Исключение бросается только при неверном вызове — неизвестной кодировке CSV или
  строгом режиме `Ldml`.

## Список кодеков

| Кодек | Что переводит | Фасад | Документация |
|---|---|---|---|
| `Json` | PHP-значения ↔ JSON | `Json::encode()`, `decode()`, `isValid()` | [Json.md](Json.md) |
| `Csv` | таблицы ↔ CSV-файлы и строки | `Csv::decode()`, `iterate()`, `encode()` | [Csv.md](Csv.md) |
| `Marshal` | PHP-значения ↔ формат `serialize()` | `Marshal::encode()`, `decode()` | [Marshal.md](Marshal.md) |
| `Base64` | бинарные данные ↔ Base64 и Base64url | `Base64::encode()`, `decode()` | [Base64.md](Base64.md) |
| `Ldml` | форматы дат PHP `date()` ↔ шаблоны LDML для JS | `Ldml::encode()`, `decode()` | [Ldml.md](Ldml.md) |

## Какой выбрать

| Задача | Кодек |
|---|---|
| Ответ API, данные в `data-*` атрибуте, настройки в БД | `Json` |
| Экспорт и импорт таблиц, файлы из Excel и 1С | `Csv` |
| Сохранить PHP-значение с объектами или сохранить без потерь типов | `Marshal` |
| Токен для ссылки, бинарные данные внутри JSON или email | `Base64` |
| Показать дату в браузере в формате из PHP-настроек | `Ldml` |

`Json` и `Marshal` пересекаются: оба сохраняют PHP-значения в строку. `Json` читается любым языком
и безопасен сам по себе, но теряет объекты и различие между списком и объектом. `Marshal`
сохраняет всё, включая объекты, но читается только PHP и требует осторожности с данными от
пользователей. Если не нужны объекты, выбирайте `Json`.

## Json

Обёртка над `json_encode()` и `json_decode()`: кириллица и слеши не экранируются, невалидный
UTF-8 не ломает кодирование, ошибки возвращают `''` или `null`.

## Csv

Чтение и запись CSV по RFC 4180 с автоопределением разделителя, переносов строк и кодировки.
`iterate()` читает файлы любого размера построчно, без роста памяти.

## Marshal

Нативный формат PHP `serialize()` с безопасным декодированием: объекты не восстанавливаются, пока
это явно не разрешено. Опционально использует igbinary.

## Base64

Base64 по RFC 4648: обычный и URL-safe вариант. Строгое декодирование понимает оба алфавита и
возвращает `null` на посторонних символах.

## Новый кодек

- **Класс** — в `expansa-cms/expansa/Codecs/`, без импортов из других пакетов `expansa/`.
  Внутри `Codecs` кодеки могут использовать друг друга: `Csv` кодирует вложенные массивы через
  `Json`.
- **Имя** — одно слово, по названию формата, а не действия: `Json`, а не `JsonEncoder`.
- **Методы** — `encode()` из PHP во внешний формат и `decode()` обратно.
- **Фасад** — в `expansa-cms/expansa/Facades/`. Класс указывается строкой в
  `getStaticClassAccessor()`, без `use`.
- **Документация** — отдельный файл в `documentation/` и строка в таблице выше.
