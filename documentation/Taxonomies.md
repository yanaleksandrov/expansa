# Таксономии и термины

Таксономия группирует записи типов по терминам: категории, метки, жанры. Таксономию регистрируют в коде,
термины создают в дашборде, запись получает их в редакторе или через `Post::setTerms()`:

```php
use App\Models\Post;
use App\Models\Term;
use App\Post\Taxonomy;

Taxonomy::register(
    key: 'genres',
    labelName: t('Genre'),
    labelNamePlural: t('Genres'),
    labelAdd: t('Add New Genre'),
    labelEdit: t('Edit Genre'),
    labelSearch: t('Search Genres'),
    types: ['books'],
    hierarchical: true,
);

$jazz  = Term::create(['taxonomy' => 'genres', 'name' => 'Jazz']);
$bebop = Term::create(['taxonomy' => 'genres', 'name' => 'Bebop', 'parent_id' => $jazz->id]);

$book = Post::get('books', 15);
$book->setTerms('genres', [$bebop->id]);
$book->terms('genres');   // [Term Bebop]
$bebop->url();            // https://example.com/genres/jazz/bebop
```

| Класс                         | Назначение                                                            |
|-------------------------------|-----------------------------------------------------------------------|
| `App\Post\Taxonomy`           | Реестр таксономий: ключ, подписи, типы записей, где видны термины     |
| `App\Models\Term`             | Термин: создание, правка, удаление, дерево, адреса, счётчики записей  |
| `App\Models\Post`             | `terms()` и `setTerms()` — термины записи                             |
| `App\Tables\Terms`            | Список терминов таксономии в дашборде                                 |
| `App\Api\Terms\TermsService`  | API дашборда и публичное дерево терминов                              |

Ядро регистрирует `categories` (иерархическая) и `tags` для страниц в `bootstrap.php`, фаза `register`.

## Хранение

Термины всех таксономий — в таблице `terms`, ключ таксономии — колонка `taxonomy`. Slug уникален внутри
таксономии: `news` может быть и категорией, и меткой. Родитель — термин той же иерархической таксономии.

Связи с записями — таблица `term_relations`: термин, таблица записи и её ID, как в `slugs`. Поля термина — EAV
`terms_fields`, `$term->field`.

| Колонка       | Что хранит                                                          |
|---------------|---------------------------------------------------------------------|
| `taxonomy`    | Ключ таксономии                                                     |
| `name`        | Название                                                            |
| `slug`        | Адрес; пустой создаётся из названия, занятый получает номер: `news-2` |
| `description` | Описание, тема может его показать                                   |
| `parent_id`   | Родитель, `0` — верхний уровень                                     |
| `position`    | Порядок среди соседей; без него — по названию                       |
| `count`       | Число опубликованных записей не в корзине                           |

`count` пересчитывает `Term::recount()`: один запрос на тип записей и одно обновление на все термины.
Его вызывают `setTerms()`, смена статуса, корзина, публикация по расписанию и удаление записи.

## Регистрация

| Параметр         | По умолчанию        | Что делает                                                      |
|------------------|---------------------|-----------------------------------------------------------------|
| `key`            | —                   | 1–32 строчные буквы, `-`, `_`; `%taxonomy%` в адресе и параметр фильтра таблицы записей |
| `labelName`, `labelNamePlural`, `labelAdd`, `labelEdit`, `labelSearch` | — | Подписи дашборда |
| `types`          | `[]`                | Типы записей, к которым относятся термины                      |
| `public`         | `true`              | У терминов есть страницы и публичное дерево в API               |
| `hierarchical`   | `false`             | Термины вкладываются друг в друга, как категории               |
| `showInMenu`     | `true`              | Список терминов — подпункт меню каждого типа                   |
| `showInEditor`   | `true`              | Выбор терминов в редакторе записи                              |
| `showInTable`    | `true`              | Колонка и фильтр в таблице записей                             |
| `showInNavMenus` | `true`              | Термины можно добавить в меню навигации                        |
| `capabilities`   | `['manage_terms']`  | Права на список и изменение терминов                           |
| `menuPosition`   | `20`                | Место в подменю типа                                            |

Повторная регистрация ключа оставляет первую таксономию. `Taxonomy::filter(['public' => true])` выбирает
по свойствам, `Taxonomy::forType('pages')` — таксономии типа.

## Права

| Право          | Что разрешает                                                   | Роли по умолчанию     |
|----------------|-----------------------------------------------------------------|-----------------------|
| `manage_terms` | Создавать, править, удалять термины, выбирать термин по умолчанию | admin, editor       |
| `assign_terms` | Назначать термины записи в редакторе                             | admin, editor, author |

С `assign_terms`, но без прав таксономии, автор выбирает существующие термины. С правами таксономии
в редакторе можно добавить новый термин по названию: поле отправляет `new:Название`.

## Термин по умолчанию

Опция `taxonomies.<key>.default` — ID термина, его выбирают действием «Сделать по умолчанию» в списке
иерархической таксономии. Запись без терминов таксономии получает его при создании и при сохранении
с пустым выбором; записи удалённого термина, оставшиеся без терминов, — тоже. Сам термин по умолчанию
не удаляется.

## Удаление

`$term->delete()` удаляет термин, его поля и связи; дети переходят к его родителю. Удалить можно
и пакетом в списке терминов.

## Адреса

Структура адресов терминов — настройка SEO `permalinks.pages.categories`, по умолчанию `%taxonomy%/%slug%`.
`%taxonomy%` обязателен: без него термины разных таксономий получили бы один адрес. В иерархической таксономии
`%slug%` — путь под slug родителей: `categories/news/world`.

```php
$term->url();                                   // полный URL, пустой у непубличной таксономии
Term::paths('categories', [3, 4]);              // [3 => 'news/world', 4 => 'sport']
Term::getByPath('categories', 'news/world');    // термин или null для чужого пути
```

## Дашборд

- Список: `dashboard/edit?table=terms&taxonomy=<key>&type=<тип>` — форма нового термина, таблица с поиском,
  счётчик ведёт к записям с термином. Подпункт меню каждого типа таксономии.
- Редактор: `dashboard/term?id=<ID>`.
- Редактор записи: выбор терминов в боковой панели; больше 20 терминов — поиск на сервере.
- Таблица записей: колонка терминов и фильтр `?<key>=<ID>` или `?<key>!=<ID>`.
- Меню навигации: источник «`term:<key>`», пункт типа `term` получает название и адрес термина.
- Группы полей: локация «Таксономия».
- Поиск дашборда: секция терминов каждой таксономии.

## API

| Маршрут                    | Право          | Что делает                                         |
|----------------------------|----------------|----------------------------------------------------|
| `POST terms/create`        | `manage_terms` | Новый термин: `taxonomy`, `name`, `slug`, `description`, `parent_id` |
| `POST terms/update`        | `manage_terms` | Правка термина `id`                                |
| `POST terms/delete`        | `manage_terms` | Удаление термина `id`                              |
| `POST terms/bulk`          | `manage_terms` | `action=delete`, `ids` через запятую               |
| `POST terms/set-default`   | `manage_terms` | Термин `id` — по умолчанию                         |
| `POST terms/search`        | `assign_terms` | Термины `taxonomy` по названию `s` для выбора      |
| `GET terms/<taxonomy>`     | публичный      | Дерево терминов публичной таксономии: `id`, `name`, `slug`, `url`, `count`, `children` |

## Хуки

| Хук            | Когда                                              | Аргументы        |
|----------------|----------------------------------------------------|------------------|
| `termsChanged` | Термин создан, изменён или удалён                  | ключ таксономии  |

`bootstrap.php` сбрасывает по нему кэш ссылок меню.
