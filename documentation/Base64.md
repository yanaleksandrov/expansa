# Введение

`Base64` кодирует бинарные данные в текст по RFC 4648: обычный Base64 и URL-safe вариант для
ссылок, токенов и имён файлов. Декодирование строгое: посторонние символы дают `null`, а не
тихо испорченные данные, как у `base64_decode()` без второго параметра.

Работать можно через фасад `Expansa\Facades\Base64` или напрямую с классом
`Expansa\Codecs\Base64`.

```php
use Expansa\Facades\Base64;

$text = Base64::encode(random_bytes(16));  // 24 символа, например 'mZ3f0Q8Xb1Kc2uPq7w+9Tg=='
$data = Base64::decode($text);              // исходные 16 байт
```

## Кодирование

```php
Base64::encode(string $data, bool $url = false): string
```

С `$url = true` используется URL-safe алфавит: `-` и `_` вместо `+` и `/`, без паддинга `=`.
Такую строку можно вставлять в URL, cookie и имена файлов без экранирования.

```php
Base64::encode('a');                      // 'YQ=='
Base64::encode("\xFB\xFF\xBF?>");         // '+/+/Pz4='
Base64::encode("\xFB\xFF\xBF?>", true);   // '-_-_Pz4'
```

## Декодирование

```php
Base64::decode(string $data): ?string
```

Один метод понимает оба алфавита, поэтому флаг `$url` при декодировании не нужен. Отсутствующий
паддинг и пробелы (например, переносы строк каждые 76 символов в письмах) допускаются. Если есть
любой другой символ, возвращается `null`.

```php
Base64::decode('-_-_Pz4');   // то же, что Base64::decode('+/+/Pz4=')
Base64::decode('YQ');        // 'a'
Base64::decode('YQ*=');      // null
Base64::decode('');          // ''
```

Пустая строка декодируется в пустую строку, а не в `null`. Проверяйте результат строго:
`=== null`.

## Когда использовать

- **Бинарные данные в тексте:** токены из `random_bytes()`, подписи, хеши в JSON или HTML.
- **URL-safe вариант:** токены в ссылках (сброс пароля, подтверждение email), подписанные URL,
  JWT.
- **Не для шифрования.** Base64 ничего не скрывает, а только меняет представление: декодировать
  его может кто угодно.

## Производительность

Накладные расходы относительно нативных функций — около 0,1 мкс на вызов: `strtr()` для
URL-safe алфавита и проверка результата.
