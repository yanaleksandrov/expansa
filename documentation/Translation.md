# Введение

Перевод строк интерфейса: плейсхолдеры, формы множественного числа, простой Markdown, локаль
запроса и список языков. Пакет находится в `Expansa\Translation`, доступ — через фасад `I18n`
и функции `t()`, `t_attr()` для шаблонов.

```php
use Expansa\Facades\I18n;

t('Hi, ::Firstname!', 'john');                                   // 'Hi, John!'
t('See the [documentation](:link)', 'https://example.com');      // ссылка
I18n::translatePlural(':count file|:count files', 5);            // '5 files'
```

| Класс                 | Назначение                                                              |
|-----------------------|-------------------------------------------------------------------------|
| `Manager`             | Перевод, плюрализация, локаль и языки; экземпляр фасада `I18n`          |
| `Internal\Markdown`   | Подмножество Markdown для переводов                                     |
| `Internal\PluralRule` | Безопасный разбор правила множественного числа gettext в замыкание       |

## Конфигурация

`bootstrap.php` вызывает `I18n::configure()` в фазе `configure`:

```php
I18n::configure(
    routes: [EX_CORE => EX_DASHBOARD, EX_PLUGINS => EX_PLUGINS . ':dirname'],
    pattern: 'i18n/%s',
    overrides: EX_I18N,
    languages: fn () => Hook::call('languages', Registry::get('languages')),
);
```

`languages` — колбэк, возвращающий список языков: `name`, `native`, `locale`, `iso_639_1`,
`country`, `nplurals`, `plural`. Он вызывается один раз, при первом обращении к языкам, поэтому
плагины успевают добавить свои через хук `languages`. Полный список из 119 языков лежит в
`dashboard/data/languages.php`. Без `languages` список пуст, а множественное число следует
английскому правилу.

## Плейсхолдеры

Значения подставляются по порядку появления:

| Плейсхолдер      | Что подставляется                                                        |
|------------------|--------------------------------------------------------------------------|
| `:name`          | значение, экранированное для HTML                                        |
| `::name`         | то же в регистре плейсхолдера: `::name`, `::NAME`, `::Name`              |
| `:name\suffix`   | значение и суффикс: `:count\st` → `1st`                                  |
| `%s`, `%d`       | значение как есть — для разметки вокруг текста: `<a href="...">`, `</a>` |

Плейсхолдер без значения остаётся в тексте. HTML самой строки экранируется, Markdown даёт
заголовки, цитаты, жирный, курсив, изображения и ссылки (только схемы без скриптов). Как в CommonMark,
`_` и `__` выделяют только на границе слова: `upload_max_filesize` и `EX_AI_KEY` остаются как есть, а `*` и
`**` работают и внутри слова.

`t_attr()` и `translateAttribute()` возвращают простой текст для атрибута, экранированный один раз.

## Множественное число

`translatePlural($forms, $count, ...$args)` выбирает форму по правилу языка текущей локали. Формы
разделяются `|` в порядке правила: у английского две (`one|other`), у русского три
(`1 файл|2 файла|5 файлов`). `:count` заменяется числом, остальные плейсхолдеры берут значения
по порядку.

```php
I18n::translatePlural(':count file in :folder|:count files in :folder', 3, 'Docs');
// en: '3 files in Docs'
// ru, перевод ':count файл в :folder|:count файла в :folder|:count файлов в :folder': '3 файла в Docs'

I18n::translateAttributePlural('One comment|:count comments', $total); // для атрибута
```

- Правило ищется по локали (`ru-RU`), затем по коду языка (`ru`); нет языка — английское `n != 1`.
- Отрицательное число выбирает форму по модулю.
- Если правило указывает на форму, которой нет, берётся последняя.
- Правило — выражение gettext из поля `plural`. Оно разбирается, а не выполняется: допустимы только
  `n`, целые числа, скобки, `?:`, арифметика, сравнения и логика. Сломанное правило языка из
  плагина заменяется английским, а не роняет страницу.

## Языки и локаль

```php
I18n::locale();                       // 'ru-RU' из Accept-Language, иначе 'en-US'
I18n::language('ru', 'iso_639_1');    // язык по полю, [] если не найден
I18n::languageOptions();              // ['ru-RU' => ['flag' => 'ru', 'content' => 'Russian - Русский'], ...]
```

`language()` строит индекс по полю при первом поиске, дальше поиск не зависит от длины списка.
Для `locale()` нужен `ext-intl`, без него возвращается значение по умолчанию.

## Производительность

`tests/benchmarks/Translation.php` сравнивает текущий код с коммитом (`--baseline=<ref>`):

| Случай          | До, µs | После, µs |                                      |
|-----------------|--------|-----------|--------------------------------------|
| простой текст   | 0.73   | 0.65      | `htmlspecialchars()` вместо `htmlentities()` |
| кириллица       | 1.32   | 1.13      |                                      |
| плейсхолдеры    | 4.1    | 3.8       | без флага `/u`, без `array_shift()`  |
| Markdown        | 4.4    | 4.2       | выражение — только при своём маркере |
| `language()`    | 0.40   | 0.19      | индекс; раньше 2 языка, теперь 119   |
| `translatePlural` | —    | 2.3       | правило кэширует индекс формы по числу |
