# Введение

Перевод строк интерфейса: плейсхолдеры, формы множественного числа, простой Markdown, локаль
запроса и список языков. Пакет находится в `Expansa\Translation`, доступ — через фасад `I18n`
и функции `t()`, `t_attr()` для шаблонов.

```php
use Expansa\Facades\I18n;

t('Hi, ::Firstname!', 'john');                                   // 'Hi, John!'
t('See the [documentation](:link)', 'https://example.com');      // ссылка
I18n::translatePlural(':count {file|files}', 5);                 // '5 files'
```

| Класс                 | Назначение                                                              |
|-----------------------|-------------------------------------------------------------------------|
| `Manager`             | Перевод, плюрализация, локаль и языки; экземпляр фасада `I18n`          |
| `Internal\Markdown`   | Подмножество Markdown для переводов                                     |
| `Internal\PluralRule` | Безопасный разбор правила множественного числа gettext в замыкание       |

## Конфигурация

`bootstrap.php` вызывает `I18n::configure()` в фазе `configure`:

```php
I18n::configure(
    routes: [EX_CORE => EX_DASHBOARD, EX_PLUGINS => EX_PLUGINS . ':dirname', EX_PATH => EX_DASHBOARD],
    pattern: 'i18n/%s',
    overrides: EX_I18N,
    languages: fn () => Hook::call('languages', Expansa\Translation\Languages::all()),
    locale: fn () => App\Models\User::current()?->locale,
);
```

Перевод строки ищется по файлу, из которого вызван `t()`: первый маршрут, путь которого содержит этот
файл, даёт каталог переводов, а `pattern` с локалью — имя файла (`dashboard/i18n/ru-RU.json`). Последний
маршрут `EX_PATH` отдаёт переводам дашборда всё остальное: `app/`, скомпилированные шаблоны в `cache/views`,
`bootstrap.php`. Файл — JSON `{"исходная строка": "перевод"}`; строки без перевода остаются английскими.

`locale` — колбэк выбранной локали, у дашборда это язык из профиля пользователя. Он вызывается один раз,
при первом переводе; `null` или пустая строка — локаль из `Accept-Language`.

`languages` — колбэк, возвращающий список языков: `name`, `native`, `locale`, `iso_639_1`,
`country`, `nplurals`, `plural`. Он вызывается один раз, при первом обращении к языкам, поэтому
плагины успевают добавить свои через хук `languages`. Без `languages` пакет берёт встроенный список
из 119 языков — `Expansa\Translation\Languages::all()`. Готовый список — `I18n::getLanguages()`.

## Плейсхолдеры

Значения подставляются по порядку появления:

| Плейсхолдер      | Что подставляется                                                        |
|------------------|--------------------------------------------------------------------------|
| `:name`          | значение, экранированное для HTML                                        |
| `::name`         | то же в регистре плейсхолдера: `::name`, `::NAME`, `::Name`              |
| `:name\suffix`   | значение и суффикс: `:count\st` → `1st`                                  |
| `%s`, `%d`       | значение как есть — для разметки вокруг текста: `<a href="...">`, `</a>` |

Плейсхолдер без значения остаётся в тексте. HTML самой строки экранируется, Markdown даёт
заголовки, цитаты, жирный, курсив, изображения и ссылки (только схемы без скриптов). Как в CommonMark,
`_` и `__` выделяют только на границе слова: `upload_max_filesize` и `EX_AI_KEY` остаются как есть, а `*` и
`**` работают и внутри слова.

`t_attr()` и `translateAttribute()` возвращают простой текст для атрибута, экранированный один раз.

## Множественное число

Меняющееся слово пишется блоком форм в фигурных скобках, остальная фраза — один раз. Формы идут в порядке
правила языка: у английского две (`{file|files}`), у русского три (`{файл|файла|файлов}`). Если в строке
есть блок, первое значение `t()` и `t_attr()` — число; остальные плейсхолдеры берут значения по порядку.

```php
t(':count {file|files} in :folder', 3, 'Docs');
// en: '3 files in Docs'
// ru, перевод ':count {файл|файла|файлов} в :folder': '3 файла в Docs'

t('{=0 No files|# file|# files}', $total);   // 'No files', '1 file', '12,345 files'
t(':count {new|new} {file|files}', 5);        // ru ':count {новый|новых|новых} {файл|файла|файлов}': '5 новых файлов'
t_attr('{One comment|# comments}', $total);   // для атрибута
```

| Запись        | Что значит                                                                 |
|---------------|----------------------------------------------------------------------------|
| `{a\|b\|c}`     | формы слова по правилу языка                                               |
| `#`           | число внутри блока                                                         |
| `:count`      | то же число в любом месте строки                                           |
| `=0 текст`    | текст для точного числа, раньше правила: `{=0 Нет файлов\|# файл\|…}`        |
| `\{`, `\}`    | буквальные скобки                                                          |

Число и в `#`, и в `:count` выводится в формате локали: `12 345` по-русски, `12,345` по-английски
(с расширением `intl`; без него — просто цифры). Несколько блоков в одной фразе следуют одному числу.
Строка с блоком, у которой первое значение не число, выводится как есть.

В файле перевода ключ — английская строка, значение — перевод с блоками своего языка. Если удобнее
переводить целыми предложениями, значение может быть списком, по предложению на форму:

```json
{
    ":count {file|files} in :folder": ":count {файл|файла|файлов} в :folder",
    "Deleted {# file|# files}.": ["Удалён # файл.", "Удалено # файла.", "Удалено # файлов."]
}
```

`tests/Translation.php` проверяет файлы переводов дашборда, плагинов и тем: в каждом блоке и списке
столько форм, сколько у языка файла (`nplurals` в `Languages`), и блоков столько же, сколько в исходной
строке. `translatePlural($forms, $count, ...$args)` и `translateAttributePlural()` фасада `I18n` —
та же запись с числом отдельным аргументом.

- Правило ищется по локали (`ru-RU`), затем по коду языка (`ru`); нет языка — английское `n != 1`.
- Отрицательное число выбирает форму по модулю.
- Если правило указывает на форму, которой нет, берётся последняя.
- Правило — выражение gettext из поля `plural`. Оно разбирается, а не выполняется: допустимы только
  `n`, целые числа, скобки, `?:`, арифметика, сравнения и логика. Сломанное правило языка из
  плагина заменяется английским, а не роняет страницу.

## Языки и локаль

```php
I18n::locale();                       // 'ru-RU': выбранная в configure(), иначе из Accept-Language, иначе 'en-US'
I18n::language('ru', 'iso_639_1');    // язык по полю, [] если не найден
I18n::languageOptions();              // ['ru-RU' => ['flag' => 'ru', 'content' => 'Russian - Русский'], ...]
```

`language()` строит индекс по полю при первом поиске, дальше поиск не зависит от длины списка.
Код языка без региона (`ru` из заголовка) становится локалью этого языка из списка: `ru-RU`. Для
`Accept-Language` нужен `ext-intl`, без него возвращается значение по умолчанию.

## Производительность

`tests/benchmarks/Translation.php` сравнивает текущий код с коммитом (`--baseline=<ref>`):

| Случай          | До, µs | После, µs |                                      |
|-----------------|--------|-----------|--------------------------------------|
| простой текст   | 0.73   | 0.65      | `htmlspecialchars()` вместо `htmlentities()` |
| кириллица       | 1.32   | 1.13      |                                      |
| плейсхолдеры    | 4.1    | 3.8       | без флага `/u`, без `array_shift()`  |
| Markdown        | 4.4    | 4.2       | выражение — только при своём маркере |
| `language()`    | 0.40   | 0.19      | индекс; раньше 2 языка, теперь 119   |
| `translatePlural` | —    | 2.3       | правило кэширует индекс формы по числу |
